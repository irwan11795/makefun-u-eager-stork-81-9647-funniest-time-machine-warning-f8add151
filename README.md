A deterministic program that writes the funniest time machine warning label — one deadpan safety notice, 96 characters, one line — to `entry.txt`.

> WARNING: If a paradox occurs, stay calm. Your replacement has been briefed and prefers your job.

## Run it

```sh
python3 main.py
```

The label is written to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, falling back to `/output`, then `output/` in this repo, then a temp directory), with no trailing newline.
